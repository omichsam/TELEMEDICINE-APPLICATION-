## Overview
A **Telemedicine Web Application** built as the final project for the **Power Learn Project (PLP)** programme. The platform connects patients with healthcare professionals digitally — enabling remote consultations, appointment booking, and medical record management.

## Features
- **Patient Portal** — registration, profile management, appointment booking
- **Doctor Dashboard** — consultation management and patient records
- **Appointment System** — real-time scheduling and notifications
- **Consultation Interface** — virtual consultation support
- **Medical Records** — secure digital health record management
- **Responsive Design** — accessible across all devices
